# Planificación de proyectos

1. Lee la estructura del repositorio, sus instrucciones y los puntos de entrada.
2. Separa requisitos observados de supuestos. Identifica interfaces, datos, dependencias y restricciones.
3. Propón la solución más simple que satisfaga la tarea; divide en hitos comprobables.
4. Para cada hito, indica archivos probables, criterio de aceptación y comando de verificación.
5. Señala decisiones que realmente dependan del usuario; continúa con las independientes.
