# Implementación

1. Localiza el comportamiento actual y reproduce el fallo cuando corresponda.
2. Convierte cada requisito de la solicitud en una comprobación observable. Para una aplicación completa, identifica todos los componentes que deben existir.
3. Haz cambios acotados que mantengan las convenciones del proyecto. Un ejemplo aislado no sustituye la aplicación solicitada.
4. Revisa los casos límite, errores y compatibilidad con las interfaces existentes.
5. Ejecuta las pruebas relevantes. Corrige cualquier fallo introducido y comprueba los requisitos pendientes antes de terminar.
