# Implementación

1. Localiza el comportamiento actual y reproduce el fallo cuando corresponda.
2. Haz un cambio acotado que mantenga las convenciones del proyecto.
3. Revisa los casos límite, errores y compatibilidad con las interfaces existentes.
4. Ejecuta la prueba o comprobación relevante. Corrige cualquier fallo introducido.
5. Resume qué cambió y qué quedó sin verificar.
