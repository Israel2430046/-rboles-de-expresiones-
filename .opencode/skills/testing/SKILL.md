# Pruebas

1. Identifica el comportamiento observable y el comando de pruebas existente.
2. Prioriza casos normales, límites y regresiones reales. Evita pruebas que solo repitan la implementación.
3. Ejecuta la comprobación más específica primero; amplía solo ante un riesgo concreto.
4. Informa comandos, resultado, fallos y entorno necesario para reproducirlos.
