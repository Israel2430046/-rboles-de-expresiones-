# Revisión de código

1. Lee el cambio y el código que lo rodea. Comprueba el requisito original.
2. Busca errores funcionales, casos límite, manejo de errores y exposición de datos.
3. Prioriza hallazgos demostrables. Cada hallazgo debe incluir ubicación, impacto y forma de corregirlo.
4. No confundas preferencias de estilo con defectos. Indica cuando la verificación fue parcial.
